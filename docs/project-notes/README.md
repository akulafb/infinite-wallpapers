# Project notes

`PROJECT-CONTEXT.md` and `PROJECT-HISTORY.md` are the design notes and change log
written while the app was built on the Glaze framework (July–August 2026). They
describe the app's design decisions and lessons learned. File paths and APIs in
them refer to the old Glaze layout (`sources/`, `@glaze/core`); the app has
since been ported to plain Electron — see the root README for the current layout.
